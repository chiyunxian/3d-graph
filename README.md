# 方程空间 · 3D 方程构图器

在线访问：**https://chiyunxian.github.io/3d-graph/**

输入三个方程，在 x、y、z 三维空间中绘制曲面和它们围出的空间图形。

## 说明

打开页面时三个输入框都是空的，需要自己输入方程，输入后点击“绘制图形”或按 Enter。

可以输入：

```
x² + y² = 1
z = 0
z = 2
```

三条方程在三维空间中围出一个封闭图形。也可以只填一个或两个方程，留空的行会被跳过。

## 支持

- 显式曲面：`z = f(x,y)`，可输入 `z = x^2 + y^2`
- 隐式曲面：`F(x,y,z) = 0`，可输入 `x^2 + y^2 + z^2 = 9`
- 三个方程输入框，初始为空，由用户自己输入
- 可只填 1—3 个方程，留空的行会被跳过
- 支持全角等号/加号、上标 `²`、空格等常见输入方式
- 坐标范围固定为 −5 … 5
- 标准采样精度固定为 36³
- 网格、坐标轴、交线显示开关
- 自动旋转、拖拽旋转、滚轮缩放、右键平移
- 曲面交线以金色点标出
- 桌面与手机响应式布局

## 数学表达式

支持 `+ - * / ^`、括号、`x y z`、`pi`、`e`，也兼容 `x²+y²＝1` 这类全角/上标写法，以及带空格的输入。支持函数：

`sin` `cos` `tan` `asin` `acos` `atan` `sinh` `cosh` `tanh`
`sqrt` `abs` `exp` `ln` `log` `log10` `floor` `ceil` `round` `sign` `pow` `min` `max`

示例：

- `z = sin(x) * cos(y)`
- `x^2 + y^2 = 4`
- `z = sqrt(x^2 + y^2)`
- `x + y + z = 2`

隐式曲面使用点云绘制，交线使用两两方程的近似交点。
